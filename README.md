# Aequitas Network website

Static site for aequitasnetwork.com, hosted on GitHub Pages.

- Edit page content in `src/*.html`; shared header, footer, and page titles live in `build.py`.
- Run `python3 build.py` to regenerate the pages in the site root, then commit.
- Styles: `assets/styles.css`. Headshots: add `assets/matthew-mckay.jpg` and `assets/jennifer-leon.jpg` (square, at least 320px).
